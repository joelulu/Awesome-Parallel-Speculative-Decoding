## 今日研究提示

1. **HC-aware speculative serving**：HyperDFlash 不只是模型侧 representation adaptation，SGLang/vLLM 的 hidden-state plumbing、anchor layout、backend contract 也可能成为新架构落地的真正瓶颈。
2. **Adaptive verification × hybrid attention backend**：vLLM 暴露的 GDN incompatibility 很适合沿 D-CUT/DSpark 继续做——当 backend 不支持 device-side query-length mismatch 时，可研究 block-aware compact verification 或 CPU/device 协同裁剪。
3. **ReTrace × GP cache 的共同视角**：都可以抽象成 `stale state → correction → reuse`。ReTrace 的 Wc 是 learned correction；GP cache 是显式时序预测。可以进一步思考 rejected suffix 是否也能做 uncertainty-aware reuse，而不是只靠 deterministic gate。
