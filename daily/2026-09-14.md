## 今日研究提示

1. **DFlow 很值得加入主脉络图。** 你之前关注 ReTrace 的 rejected suffix 利用，DFlow 与它几乎形成一条独立研究主线：`rejected verifier state → cross-round conditioning → next-round draft`。后续最值得比较的是两者使用的状态、对齐方式、训练目标，以及能否与 Draft-OPD / DSpark 同时使用。
2. **高并发研究要从“验证长度”升级到“后端契约”。** DSpark 的 adaptive verification 在理论上解决 verification waste，但 Engram、GDN、MoE router、CUDA Graph 都可能对 ragged / dynamic shape 有额外限制。
3. **DFlash2 的系统评测建议固定加两类指标：** `accept len / accept rate` 健康检查，以及按 concurrency/context 切分的 kernel stability。只看 tok/s 或功能正确性会漏掉“静默失效”。
