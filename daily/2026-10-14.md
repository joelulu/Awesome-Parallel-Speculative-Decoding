### D-Loop — 2026-10-05

- **解决什么问题：** 单次并行草拟看不到已选前驱，邻近位置可能重复同一 token，导致早拒绝。
- **DFlash 为什么需要：** 直接复用 DFlash target 特征条件和 token 接口，值得纳入块内因果路线。
- **方法核心：** 首轮生成整块后选高置信前缀，第二轮把前缀作为可见 token、重新 mask 后缀；互补前缀/后缀目标训练同一骨干。
- **长期路线：** 直接复用 DFlash target 特征条件和 token 接口，值得纳入块内因果路线；需多一次 drafter forward，论文主要在 Qwen3-4B/8B 八项任务验证，不能假定高并发仍获益。
- **原始来源：** [arXiv](https://arxiv.org/abs/2610.06011) · [全文](https://arxiv.org/html/2610.06011v1)

### DLoop — 2026-10-06

- **解决什么问题：** 当 target 常接受整块时，每个短草稿后立即验证会浪费昂贵的 target forward。
- **DFlash 为什么需要：** 论文明确在 DFlash、DSpark 等并行草稿上评估，值得纳入 Verification Cost。
- **方法核心：** 置信度控制的多阶段草拟把候选累积后一次验证；训练时让后续草拟接触自身未验证 token 的 hidden states。
- **长期路线：** 论文明确在 DFlash、DSpark 等并行草稿上评估，值得纳入 Verification Cost；5–41% wall-clock 增益为作者报告且依赖 drafter/target 成本比。与 D-Loop 2610.06011 是不同论文。
- **原始来源：** [arXiv](https://arxiv.org/abs/2610.07659)

### EDR — 2026-10-07

- **解决什么问题：** 块内 CE 或接受长度替代目标忽略一轮拒绝位置如何改变后续轮起点，无法直接优化全局 target 调用次数。
- **DFlash 为什么需要：** 论文引用 DFlash 固定位置衰减权重，但实验微调的是 DSpark/DFly，尚未证明 DFlash 上的收益。
- **方法核心：** 将解码表示为 Markov reward process，推导精确 EDR 目标与时间差分梯度，并用 target rollouts 作无偏随机优化。
- **长期路线：** 论文引用 DFlash 固定位置衰减权重，但实验微调的是 DSpark/DFly，尚未证明 DFlash 上的收益；值得加入 Training 候选路线并标明待验证。
- **原始来源：** [arXiv](https://arxiv.org/abs/2610.10411) · [全文](https://arxiv.org/html/2610.10411v1)

### DCOCO — 2026-10-08

- **解决什么问题：** DFlash 各位置独立取最高分 token，缺少相邻已选 token 的条件关系，早期错误导致整块后缀作废。
- **DFlash 为什么需要：** 作者称 DFlash Contextual Corrector，直接在 DFlash 候选上工作。
- **方法核心：** 用 DFlash 单次 forward 的 hidden states、候选 token 与 logits 构造相邻位置候选网格；轻量 MLP 并行评分边，再顺序选取路径。
- **长期路线：** 作者称 DFlash Contextual Corrector，直接在 DFlash 候选上工作；值得纳入块内因果与 Candidate Search。作者报告并发 4–32 较最强基线高 6–23%，但路径选择仍有顺序步骤。
- **原始来源：** [arXiv](https://arxiv.org/abs/2610.12570) · [全文](https://arxiv.org/html/2610.12570v1)
